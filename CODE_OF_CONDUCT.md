# Code of Conduct

## Our standard

We want this project to remain useful and welcoming to people with different backgrounds, languages, and levels of technical experience. Be respectful, specific, and patient.

## Expected behavior

- Give feedback about the work, not the person.
- Explain problems with enough context to be actionable.
- Assume good intent while still addressing harm.
- Avoid sharing private information or credentials.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate disruption, credential sharing, and unwanted personal contact are not acceptable.

Project maintainers may remove comments, reject changes, or limit participation when necessary to keep the project safe.
